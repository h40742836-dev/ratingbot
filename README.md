# Рейтинг: Telegram-бот + мини-приложение

## Из чего состоит
- `bot/main.py` — бот (aiogram): /start, регистрация, ID, рефералы, /profile
- `backend/main.py` — сервер (FastAPI): проверка подписи Telegram, /api/me, отдаёт окно
- `backend/tournaments.py` — вся логика: турниры, сетка, профиль, топ, поиск, админка, FAQ, оценка
- `backend/engine.py` — расчёт MMR, калибровка, десятки, серии, «огонёк», титулы
- `miniapp/index.html` — само окно (профиль, турниры, топ, FAQ, админ)
- `db/schema.sql` — таблицы базы; `docker-compose.yml` — запуск базы; `.env` — токен и пароли (НЕ показывать никому)

## Как запустить (3 терминала + Docker)
1. Открыть Docker Desktop, в папке проекта: `docker compose up -d`
2. Терминал 1 (бот): `source .venv/bin/activate` → `python bot/main.py`
3. Терминал 2 (сервер): `source .venv/bin/activate` → `uvicorn backend.main:app --port 8000 --reload`
4. Терминал 3 (ссылка наружу): `ssh -o ServerAliveInterval=30 -R 80:localhost:8000 nokey@localhost.run`
   → новую ссылку https://....lhr.life вставить в BotFather → Mini Apps → Menu Button → Save
Ссылка меняется при каждом запуске туннеля. Постоянной она станет после переноса на хостинг.

## Правила (из ТЗ заказчика)
- Победа +5, блестящая +10, поражение -2. Регистрация +100. MMR виден сразу, ранг выдаётся после калибровки.
- Калибровка 10 игр: пока она идёт, в профиле показывается она вместо ранга; после неё выдаётся ранг.
- Десятка = 10 побед. Бонус: 1-я +100, 2-9-я +50 (win rate ≥ 50%), 10-я и дальше +35 (≥ 70%).
- Рефералы: первые 10 по +10, дальше по +5.
- Роли: создатель > админ > игрок. Сброс, удаление, ручные победы, красивые ID и выдача админки — только создатель.

## Безопасность
